# SGSSS Brand Extension For Quarto

SGSSS Quarto Brand Extension with icons and colour palette to use for SGSSS materials created with Quarto.

## Installing

```bash
quarto add SGSSSonline/sgsss-brand-yml
```

This will install the extension under the `_extensions` subdirectory.
If you're using version control, you will want to check in this directory.

## Using

This extension installs a [brand.yml](https://posit-dev.github.io/brand-yml/) configuration for SGSSS.
